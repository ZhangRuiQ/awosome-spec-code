# 安全红线

## 1. 代码安全

### 绝对禁止

| 红线 | 说明 |
|------|------|
| ❌ 硬编码密钥 | 禁止在代码中硬编码 AK/SK、数据库密码、API Key |
| ❌ 硬编码敏感配置 | 禁止在代码中写死数据库连接串、Redis 密码 |
| ❌ 敏感信息入仓 | 禁止提交包含用户个人信息的测试数据 |
| ❌ 敏感信息日志 | 禁止在日志中打印手机号、身份证、银行卡等敏感信息 |

### 正确处理

```java
// ✅ 正确：从配置中心读取
@Value("${db.password}")
private String dbPassword;

// ✅ 正确：日志脱敏
log.info("用户操作, userId={}, phone={}", userId, maskPhone(phone));
```

## 2. 输入安全

### SQL 注入防护

- 使用参数化查询，禁止字符串拼接 SQL
- MyBatis 使用 `#{}` 而非 `${}`

```java
// ✅ 正确
orderDAO.queryByStatus(@Param("status") status);

// ❌ 错误 - SQL 注入风险！
String sql = "SELECT * FROM order WHERE status = '" + status + "'";
```

### XSS 防护

- 用户输入必须转义后输出
- 使用框架提供的 HTML 转义工具

## 3. 业务安全

### 资金相关

| 红线 | 处理方式 |
|------|----------|
| ⚠️ 涉及资金变更 | 必须在 spec 中明确标注，人工审查后方可编码 |
| ⚠️ 涉及金额计算 | 使用 Decimal/BigDecimal，禁止浮点数 |
| ⚠️ 涉及退款 | 必须校验退款金额 ≤ 实付金额 |

### 状态流转

| 红线 | 处理方式 |
|------|----------|
| ⚠️ 涉及状态机 | 必须检查状态流转合法性，禁止直接 set |
| ⚠️ 涉及并发状态变更 | 必须使用乐观锁/分布式锁 |

### 权限控制

| 红线 | 处理方式 |
|------|----------|
| ⚠️ 涉及权限变更 | 必须显式校验操作人权限 |
| ⚠️ 涉及数据越权 | 必须校验数据归属 |

## 4. 资源安全

### 并发安全

- 共享资源访问必须使用同步机制
- 分布式场景使用分布式锁

### 资源释放

- 数据库连接必须关闭
- 文件句柄必须释放
- 锁必须最终释放（try-finally）

## 5. 外部交互安全

### 接口调用

- 外部接口必须设置超时
- 必须做降级/熔断处理
- 必须校验返回值

### 数据序列化

- 禁止反序列化不可信数据
- JSON 解析设置深度限制

## 6. 安全检查清单

提交前自检：

- [ ] 没有硬编码密钥/密码
- [ ] 没有敏感信息泄露到日志
- [ ] SQL 使用参数化查询
- [ ] 用户输入做了校验和转义
- [ ] 资金计算使用 Decimal
- [ ] 状态变更有合法性检查
- [ ] 权限操作有显式校验
- [ ] 外部调用有超时设置
